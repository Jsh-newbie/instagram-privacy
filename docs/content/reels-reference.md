## 캡션 구조 패턴

성과가 좋은 릴스의 공통 구조:

1. **훅 (첫 줄)** — 대상 직접 호명 또는 문제 제기
   - 예: "중3 친구들 안녕?" / "고민이 많았을 거에요"
2. **공감 & 맥락** — 학생/학부모 입장에서 고민 언급
3. **신뢰 근거** — "과학고 출신", "고1 가르치면서"
4. **자료 소개** — 구체적 범위와 분량 명시
5. **CTA** — 받는 법 단계별 안내 (① ②)
6. **부가 행동 유도** — 좋아요 / 저장 / 공유
7. **안전망** — "안 됐으면 DM 주세요"
